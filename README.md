## 🚀 Free Deployment to GitHub Pages

1. Create a repository on GitHub (e.g. `portfolio`).
2. Push this folder:
   ```bash
   git init
   git add .
   git commit -m "Add Kartik's portfolio with Starbucks AI and Spam Ham"
   git branch -M main
   git remote add origin https://github.com/kartik444x/portfolio.git
   git push -u origin main
   ```
3. In GitHub: **Settings** → **Pages** → Source: **Deploy from branch** → Branch: `main` → Save.
4. Your website is live in ~1 minute at `https://kartik444x.github.io/portfolio/`!
